PC BRIDGE 1.6.0
===============
Интерфейс
- Веб-панель (трей -> «Панель управления», двойной щелчок по значку): http://127.0.0.1:8767,
  только с этого ПК, ссылка с ключом (меняется при каждом запуске). Вкладки:

  (поиск, фильтр по модулю, только ошибки / изменения / опасные), Изменения файлов
  (разница «было / стало» рядом, отмена одного или нескольких изменений галочками).
- Окно подтверждения опасной команды: вся команда с подсвеченными опасными местами,
  причины, папка, таймер. Кнопки: Запретить (по умолчанию) / Разрешить один раз /
  Разрешить похожие на 10 мин (similar_allow_minutes). Кнопки «Разрешить» активны через
  1,5 с - случайный Enter ничего не разрешит. Удаление с диска / из системных папок
  «похожими» не разрешаются. Если окно не открылось - старый диалог.

- Значок: зелёный - работает, жёлтый - пауза (полоски) или только чтение (замок),
  красный - ошибка, серый - запуск. Мигает, пока агент что-то делает.
- Уведомления с кнопками: «Агент изменил 3 файла» [Показать] [Отменить] (одно на пачку
  правок), «Отказано в команде» [Открыть ленту]. Отмена всегда с просмотром разницы.
- Новые ключи config.json: panel_port (8767), ctrl_port (8768), similar_allow_minutes (10),
  toast_buttons (true).

PC BRIDGE 1.4.0
===============
Основная идея прежняя: Notion-агент подключается к ПК через MCP-сервер и ngrok,
адрес и токен не меняются.

Работа в фоне
- Мост больше не зависит от окна START.bat: сервер, ngrok и ИИ-моделью
  управляет supervisor.py (значок в трее).
- Автоперезапуск: если сервер или ngrok упали (сон, обрыв сети), они
  перезапускаются с паузой 2-5-10-30-60 с. Раз в минуту публичный адрес
  проверяется снаружи; после пробуждения - сразу. Ошибки, которые
  перезапуск не исправит (неверный токен, чужой домен), показываются
  уведомлением без бесконечных попыток.
- По желанию - автозапуск при входе в Windows (ярлык в папке «Автозагрузка»).

Контроль
- Значок в трее: состояние и что агент делает сейчас; Пауза (агент получает
  отказ на всё), Только чтение, Уведомления, скопировать адрес/токен,
  Остановить всё. Цвет: зелёный - работает, синий - только чтение,
  жёлтый - пауза, серый - запуск, красный - ошибка.
- Горячие клавиши: Ctrl+Alt+Shift+P - пауза, Ctrl+Alt+Shift+S - остановить всё.
- Режим «только чтение» (в трее или навсегда в настройках): смотреть, искать,
  делать скриншоты можно, менять - нельзя.
- Уведомления Windows: агент подключился, команда отклонена, туннель упал
  или поднялся, сменился адрес.

ИИ-проверка команд (по желанию)
- START.bat сам скачивает llama.cpp и модель Qwen2.5-Coder 3B или 1.5B (с докачкой),
  модель запускается вместе с мостом и работает без интернета.
- Правила остаются главными. Модель смотрит только то, что правила пропустили
  (и не смотрит очевидно безопасное: git status, npm test...). Она может только
  показать окно Да/Нет, но никогда не разрешает запрещённое. Если модель
  не ответила - решают одни правила. Ответы кэшируются.

Новые инструменты
- Отмена изменений без git: перед каждой правкой, перезаписью, переносом или
  удалением сохраняется прежняя версия (папка history). list_changes,
  undo_change.
- copy_path, move_path (и переименование), make_zip, extract_zip.
- edit_file_multi: несколько правок в файле за один вызов (всё или ничего).
- clipboard_get / clipboard_set, open_path (файл или ссылка в обычной программе).
- system_stats (CPU, память, диски), list_processes, kill_process (зависшие
  программы; системные процессы и сам мост закрыть нельзя).
- read_screen_text (OCR скриншота встроенным распознаванием Windows),
  click_text (найти кнопку по тексту и нажать).

Установка
- Новые библиотеки: psutil, pystray (START.bat ставит сам).
- STOP.bat останавливает супервизор и всё, что он запустил.


PC BRIDGE 1.3.1
===============
Исправления и безопасность. Основная идея не менялась: Notion-агент
подключается к ПК через MCP-сервер и ngrok, адрес и токен прежние.

Ошибки
- edit_file: в файлах с концами строк CRLF вставленный текст больше не
  получает LF-строки, если old_string была однострочной.
- По тайм-ауту и job_stop останавливается всё дерево процессов
  (powershell -> cargo -> rustc и т.п.), а не только верхний процесс.
- Медленные инструменты (поиск, git, скриншоты, файлы, мышь) выполняются
  в отдельных потоках и не замораживают сервер для других запросов.
- type_text печатает по-русски и любые символы напрямую (Unicode),
  многострочный текст вставляет через буфер и возвращает прежний буфер.
  Раньше русский текст через PowerShell мог превращаться в "кракозябры".
- press_keys работает при любой раскладке (раньше ломался на русской),
  есть presses=N, понятная ошибка для пустых и неизвестных клавиш.
- job_status/job_stop: понятная ошибка для неизвестного job_id, журнал
  задачи закрывается после её завершения.
- blender_render: исправлена установка samples.
- download_file: недокачанный файл не остаётся (качается в .part).
- roblox_serve: старый rojo останавливается вместе с потомками, журнал
  закрывается; без default.project.json - понятная ошибка.

Безопасность
- Опасные команды только с разрешения: run_command узнаёт реально опасные команды
  (формат диска, удаление системных папок и профиля, отключение антивируса,
  пароли, автозапуск, git push --force...) и показывает на ПК окно Да/Нет.
  Обычные команды выполняются без вопросов. Агент не может подтвердить сам:
  отвечает только человек за ПК. Настройка dangerous_commands = ask/block/off.
- STOP.bat и START.bat останавливают только свои процессы (проверка PID
  и времени запуска), а не случайную программу с тем же PID.
- delete_path отправляет в Корзину; удалить навсегда - permanent=true.
- http_get/download_file не ходят на адреса локальной сети
  (роутер, NAS, 169.254.x.x). localhost разрешён. Разрешить сеть:
  "allow_lan_urls": true в config.json.
- http_get читает не больше 5 МБ (max_page_mb в config.json).
- Установщик проверяет цифровую подпись Python (Python Software
  Foundation), ngrok и Roblox Studio; для ARM64 скачиваются ARM64-версии.
- ngrok запускается без журнала запросов (--inspect=false): содержимое
  файлов и токен не хранятся на 127.0.0.1:4040.
- В старом режиме (ключ в адресе) сервер не пишет адреса запросов в лог.
- Чтение файлов, поиск, скриншоты, клики и клавиши тоже пишутся
  в logs\tools.log (сам набираемый текст - нет, только длина).
- Более явные предупреждения в мастере про командную строку и старый
  режим входа.

Обслуживание
- tools.log ограничен (5 МБ x 3 файла), журналы задач и временные
  скрипты Blender старше 7 дней удаляются при запуске.
- Запись файлов атомарная (через временный файл).
- Версии библиотек закреплены; добавлена send2trash.
- Тесты: RUN_TESTS.bat (tests\test_server.py).
- Номер версии берётся из VERSION.txt.


PC BRIDGE 1.3
=============

Работа с кодом
--------------
- Новый инструмент edit_file: точечная замена фрагмента вместо перезаписи
  всего файла. Если фрагмент не найден или встречается несколько раз,
  файл не меняется, а агент получает подсказку с номерами строк.
- read_text_file показывает номера строк и читает диапазон строк
  (start_line / end_line). Исправлена ошибка 1.2: у файлов длиннее
  50 000 символов терялось начало.
- Новый инструмент search_files: поиск по тексту или regex с маской файлов,
  строками контекста и режимом "только файлы". Пропускает .git, target,
  node_modules, бинарные и очень большие файлы.
- list_files: маска имён (glob) и пропуск служебных папок при рекурсивном обходе.
- Новые инструменты git_status, git_diff, git_log, git_show (только чтение).
- write_text_file и edit_file сохраняют окончания строк (CRLF/LF) и BOM.
  В 1.2 на Windows любой записанный файл получал CRLF.
- В мастере настройки можно выбрать рабочую папку (например, корень репозитория).

Скриншоты
---------
- Модуль "Экран" разделён на "Скриншоты" и "Мышь и клавиатура":
  скриншоты можно включить без управления мышью.
- screenshot снимает одно окно по части заголовка или имени программы,
  даже если его закрывают другие окна; также все мониторы и только
  содержимое окна без рамки.
- Новый инструмент list_windows.
- Правильные координаты на экранах с масштабированием (125%, 150%).
- Координаты мыши берутся из последнего скриншота, в том числе снимка окна.

Вход
----
- Вход по токену (по умолчанию): адрес вида https://.../mcp, токен
  передаётся в заголовке Authorization: Bearer <токен> (или X-API-Key).
  Запросы без токена получают ответ 401 и записываются в журнал.
- Старый способ (ключ в адресе) остаётся: SETTINGS.bat -> "Вход по токену?" -> n.
- Самопроверка при запуске проверяет и вход с токеном, и отказ без него.
- В окне START.bat: U - скопировать адрес, T - скопировать токен.
- Токен сохраняется в TOKEN.txt.
